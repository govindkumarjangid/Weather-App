<h1 align="center">🌦️ SkySync Weather App</h1>

<p align="center">
  A premium, beautiful glassmorphic weather app showing real-time weather forecasts and comprehensive atmospheric details.
</p>

<hr />

<h2>📌 Description</h2>
<p>
  <b>SkySync</b> provides live and accurate weather updates for any city around the world.
  It fetches real-time data from the OpenWeatherMap API and displays a rich dashboard of essential weather metrics such as
  temperature, feels-like temperature, humidity, visibility, pressure, wind speed, and wind direction.
</p>

<p>
  The app features a <b>stunning glassmorphic UI</b> with interactive background glows, responsive data display, and
  seamless unit toggling (°C/°F) to generate a visually beautiful user experience.
</p>

<hr />

<h2>✨ Key Features</h2>
<ul>
  <li>🌍 <b>Search</b> weather by city name with a quick-access chips panel</li>
  <li>🌡️ <b>Extensive Dashboard:</b> Displays precise temperature, min/max, feels like, humidity, wind speed, pressure, visibility, and daylight details (sunrise/sunset)</li>
  <li>🕒 <b>Real-time data</b> using the OpenWeatherMap API directly</li>
  <li>🎨 <b>Premium Glassmorphic UI</b> with dynamic background glows and responsive design</li>
  <li>🌡️ <b>Unit Toggle:</b> Seamlessly switch between Celsius (°C) and Fahrenheit (°F)</li>
  <li>💾 <b>Local History:</b> Caches up to 6 of your most recently searched cities using LocalStorage</li>
</ul>

<hr />

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Frontend:</b> HTML5, CSS3 (Glassmorphism), Vanilla JavaScript</li>
  <li><b>API:</b> OpenWeatherMap API</li>
  <li><b>Assets:</b> FontAwesome (Icons), Google Fonts (Poppins & Outfit)</li>
</ul>

<h2>🚀 Example Use Case</h2>
<p>
  Enter a city name like <b>London</b> or click one of the quick-access chips.
  The app instantly processes the search, saves it to history, and displays a comprehensive grid of:
</p>

<ul>
  <li>🌡️ Current, Min/Max and Feels-Like Temperatures</li>
  <li>☁️ Detailed weather condition and cloudiness</li>
  <li>💧 Humidity level and Visibility distance</li>
  <li>🌬️ Wind speed, gusts, and degree direction</li>
  <li>🌅 Sunrise and Sunset times with daylight duration</li>
</ul>

<p>
  You can effortlessly flip the temperature readouts between °C and °F using the toggle at the top right.
</p>
